# spekk init — One Command to Opt a Project In

The recommended workflow is `spekk init` → `spekk coach` → `spekk builder`. `spekk init` is the opt-in gesture: it creates the `specs/` directory that tells spekk (and any installed spekk agents) that this project uses spec-driven development. It does nothing else — no config files, no dotfiles, no scaffolding beyond a short README so the directory is git-trackable and self-explanatory.
