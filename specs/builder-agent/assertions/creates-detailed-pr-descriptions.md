# Builder Creates Detailed PR Descriptions

When the builder creates pull requests, it provides comprehensive descriptions that explain the implementation and how it addresses the specifications.

## Success Criteria

- [ ] PR titles clearly describe the feature/fix implemented
- [ ] PR body includes "Summary" section with 2-3 bullet points of what was implemented
- [ ] PR body includes "Test plan" section with verification steps
- [ ] PR body references the specific specs and assertions addressed
- [ ] PR body explains any implementation decisions or trade-offs made
- [ ] PR body follows consistent markdown formatting
- [ ] PR descriptions help reviewers understand the scope and impact of changes
