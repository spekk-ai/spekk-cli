# Emphasizes Status and Priority Visually

## Assertion

The interface uses visual indicators to clearly show the status and priority of each spec and assertion.

## Success Criteria

- Different status values (not_started, in_progress, done) have distinct visual indicators (colors, icons, badges)
- Priority levels (1, 2, 3) are visually differentiated 
- Visual indicators are consistent throughout the interface
- Status and priority are visible both in tree view and detail panel
- High priority or in-progress items are easily identifiable at a glance

## Test Plan

- Verify color coding or icons for different statuses
- Check that priority levels have visual distinction
- Confirm indicators appear in both tree and detail views
- Test with specs/assertions having different status/priority combinations
