# CLI Supports Group Navigation and Filtering

CLI commands can work with grouped specs and provide group-aware navigation.

## Success Criteria

- [ ] `npm run next` can prioritize within specific groups
- [ ] Status commands show group hierarchies in output
- [ ] Web interface displays expandable group trees
- [ ] Group status rollups are calculated and displayed
- [ ] Cross-group spec references are resolved correctly
- [ ] Filtering by group is supported in relevant commands
