# Structured Assessment Report

Business model validation produces a comprehensive report with quantitative scoring and actionable recommendations.

## Success Criteria

Report includes all required sections:
- Overall health score (X/Y points, percentage)
- Strengths (key positive findings)
- Concerns (major gaps or risks)
- Unanswered/unclear items
- Priority hypotheses to test (next 6 months)
- Recommended actions (specific next steps)

## Report Format

```
BUSINESS MODEL VALIDATION REPORT
================================
Overall Health Score: X/Y points (Z%)

Strengths:
- [Key positive findings]

Concerns:
- [Major gaps or risks]

Unanswered/Unclear:
- [Questions that need clarification]

Priority Hypotheses to Test (Next 6 Months):
1. [Most critical assumption to validate]
2. [Second priority]
3. [Third priority]

Recommended Actions:
- [Specific next steps]
```

## Output Requirements

- Save report as `business-model-validation.md` in relevant project folder under `/projects`
- Create project folder if it doesn't exist
- Report is actionable and constructive
- Scoring is transparent and explained
