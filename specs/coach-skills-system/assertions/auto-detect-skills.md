# Auto-Detect Skills

Coach automatically detects when to suggest specialized skills during conversations.

## Success Criteria

- When user mentions business model, startup validation, or founder assessment → coach suggests business-model-validator skill
- Detection happens automatically without explicit skill requests
- Coach explains why the skill would be helpful before using it
- Users can accept or decline skill suggestions

## Examples

**Trigger phrases:**
- "validate this business model"
- "assess this startup"
- "founder wants to..."
- "business plan review"
- "is this viable?"

**Coach response:**
"I can use my business-model-validator skill to systematically assess this through structured questions and provide a quantitative health score. Would you like me to do that?"
