# Dual Observer Implementation Creates Confusion

## Issue Description
The system has both a programmatic observer implementation (`src/observer/programmatic.js`) and a Claude agent implementation (current session), creating potential confusion about which is the primary observer.

## Evidence
- **Claude Agent Implementation:** Currently active (this session) with intelligent reasoning capabilities
- **Programmatic Implementation:** Still exists in `src/observer/programmatic.js` with pattern-matching logic
- **CLI supports both:** `--programmatic` flag allows switching to legacy mode
- **Existing observations:** The 4 existing observations appear to be from programmatic observer

The Observer Agent prompt clearly states the programmatic detection should "become a tool the Claude agent can optionally use," but the relationship isn't clearly defined.

## Impact
Unclear which observer is authoritative, potential for conflicting or duplicate observations, and confusion about which implementation to maintain or improve.

## Recommendation
Clarify the relationship between implementations:
1. Establish Claude Agent as primary observer (current architecture supports this)
2. Position programmatic observer as optional tool for Claude Agent to use
3. Update documentation to clearly define roles and when to use each approach
