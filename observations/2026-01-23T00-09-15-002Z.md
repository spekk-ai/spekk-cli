# NPM Scripts Don't Launch Claude Agent Sessions

## Issue Description
The assertion `npm-scripts-launch-agents` specifies that `npm run coach` and `npm run builder` should launch Claude Code sessions with bash loops, but the current implementation points to Node.js CLI scripts instead.

## Evidence

**Spec Requirements (specs/spekk-cli/assertions/npm-scripts-launch-agents.md):**
```bash
# Should be bash loops like this:
while true; do
  claude --dangerously-skip-permissions << 'EOF'
You are the Coach Agent - read the prompt and follow instructions exactly.
EOF
done
```

**Current Implementation (package.json):**
```json
"scripts": {
  "coach": "node src/coach/cli.js",
  "builder": "node src/builder/cli.js"
}
```

The current scripts launch Node.js CLI wrappers rather than direct Claude Code sessions with the required looping behavior.

## Impact
Coach and Builder agents may not have the expected interactive Claude Code experience and continuous looping behavior described in orchestration specs.

## Recommendation
Either:
1. Update package.json scripts to use bash loops that launch Claude Code directly, OR
2. Update the spec to match the current Node.js CLI wrapper implementation
