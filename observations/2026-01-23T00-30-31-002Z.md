# NPM scripts spec describes outdated implementation behavior

## Issue Description
The spec "npm-scripts-launch-agents" describes current behavior as "just prints prompt" but the actual implementation properly launches Claude Code sessions as required.

## Evidence
**Spec claims (npm-scripts-launch-agents.md:34-40):**
```
Both scripts currently only display their prompts instead of launching Claude Code sessions:

// Current behavior: just prints prompt
console.log(promptContent);
console.log('You are now the Builder Agent...');
```

**Actual implementation (src/coach/cli.js:13-18):**
```javascript
const claudeProcess = spawn('claude', ['--dangerously-skip-permissions'], {
  stdio: ['pipe', 'inherit', 'inherit']
});

claudeProcess.stdin.write('You are the Coach Agent - read the prompt and follow the instructions exactly.\n');
```

**Actual implementation (src/builder/cli.js:96-101):**
```javascript
const claudeProcess = spawn('claude', ['--dangerously-skip-permissions'], {
  stdio: ['pipe', 'inherit', 'inherit']
});

claudeProcess.stdin.write('You are the Builder Agent - read the prompt and follow the instructions exactly.\n');
```

## Impact
The specification incorrectly documents the system's current behavior, which can mislead developers and indicates the spec was not updated when the implementation changed.

## Recommendation
**Update specification to reflect current state:**
1. Remove "Current Issue" section describing console.log behavior
2. Update spec to acknowledge the scripts now properly launch Claude Code
3. Mark the requirement as implemented/completed
4. Consider updating spec status from current state to reflect this is working as intended
