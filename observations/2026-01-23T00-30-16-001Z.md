# Implementation code exists outside required src/ directory

## Issue Description
The spec "no-implementation-outside-app" (marked as "done") explicitly requires all implementation code to live under the `src/` directory, but active implementation files exist in the `app/` directory.

## Evidence
**Spec requirement (src/parser/assertions/no-implementation-outside-app.md:13):**
```
All implementation code lives under the `src/` directory.
```

**Actual implementation files in app/:**
- `app/spec-validator/cli.js` - CLI interface
- `app/spec-validator/run-sidecar-tests.js` - Core logic  
- `app/cli/__tests__/npm-scripts.test.js` - Test file

**Package.json references:**
- Test script points to `app/spec-validator/cli.js`

## Impact
This violates the established architectural constraint and creates confusion about the project structure. The spec is marked as "done" but the implementation does not comply, indicating either:
1. The spec needs updating to accept both directories
2. Code needs moving from app/ to src/
3. The spec status is incorrectly marked as done

## Recommendation
**Immediate action needed:**
1. Review whether both `src/` and `app/` directories should contain implementation code
2. If only `src/` should contain code, move files from `app/` to appropriate `src/` locations
3. If both are acceptable, update the spec to reflect the current architecture
4. Update the spec status to reflect actual compliance
